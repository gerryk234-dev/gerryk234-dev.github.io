# DELTA — website

**https://gerryk234-dev.github.io/**

- **`/` — the public front end** (what visitors see): `index.html`, the DELTA marketing site
  (Home, The Experience, Analysis, The Method, Awakening, Community, Explore, Join).
- **`/app/` — the interactive platform demo**: member portal, community (Today, Feed), guided methods,
  AI assistant and admin. It runs in the visitor's browser in demo mode: test payments only, emails
  appear in the demo mailbox, and demo data stays in each visitor's own browser.

This repository only holds the built site. The source code is private (`delta-platform`;
the front end is kept there in `frontend/index.html`).
